OA badge types — colors and definitions
BadgeOA typeOSU color usedMeaningText color

Green OA Green Pine Stand #4a773c Free via repository (PMC, preprint, institutional) White (5.3:1)
Bronze OA Bronze Solar Flare #d3832b Free on publisher site, no open license Black required (7.0:1 ✓ vs white 2.98:1 ✗)
Hybrid OA Hybrid Stratosphere #006a8e Open-access article in subscription journal (APC paid) White (6.0:1)
Closed Closed Neutral-200 #e9e5e4 No free version available Neutral-800 (10.3:1)

Color logic: Gold → Luminance (natural semantic pairing, the strongest contrast). Green → Pine Stand. Bronze → Solar Flare with black text required. Hybrid → Stratosphere. Closed → same neutral palette as the citation count badge to avoid drawing undue attention.

FWCI display logic
FWCI valueBadge shown?Rationale
Not availableNoOpenAlex hasn't computed it yet
≤ 1.0NoAt or below world average — no highlight warranted
> 1.0FWCI 1.8Above world average — orange badge draws attention

Suppressing low FWCI values avoids surfacing poor scores for new papers that haven't yet accumulated citations. A 2025 paper with FWCI 0.2 is completely normal — showing it as a badge would be misleading.
