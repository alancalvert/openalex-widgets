OSU COH — OpenAlex Widget Design Reference

Visual design reference for the three OpenAlex API widgets built for the OSU College of Health Drupal 10 site (Madrone theme). Covers all three widget types × three CSS class variants, with WCAG 2.2 AA contrast verification for all badge colors. Hover FWCI values and OA badges for tooltip examples.

OSU College of Health, Web & Digital · 2026 · github.com/OSU-COH/OpenAlex-widgets

Note: External link arrows (↗) and ARIA labels are added automatically by the Drupal Link Purpose module — they are intentionally absent from widget markup.

Badge text renders at ~0.75em (≈10–11px at typical body sizes) — well below 18px, so the strict 4.5:1 threshold applies. All pass.

⚠ Bronze OA (Solar Flare): must use black text. White text on #d3832b = 2.98:1 — fails AA. This is a known limitation of the OSU brand color palette (originally designed without WCAG digital requirements).

OA badge types — colors and definitions
BadgeOA typeOSU colorMeaningText color
Gold OA Gold Luminance #ffb500 Published in a fully open-access journal Black (11.9:1)
Green OA Green Pine Stand #4a773c Free via repository (PMC, preprint, institutional) White (5.3:1)
Bronze OA Bronze Solar Flare #d3832b Free on publisher site, no open license Black required (7.0:1 ✓ — white fails at 2.98:1)
Hybrid OA Hybrid Stratosphere #006a8e Open-access article in subscription journal (APC paid) White (6.0:1)
Closed Closed Neutral-200 #e9e5e4 No free version available Neutral-800 (10.3:1)
FWCI badge display logic
FWCI valueBadge shown?Rationale
Not availableNoOpenAlex hasn't computed it yet
≤ 1.0NoAt or below world average — no highlight warranted
> 1.0FWCI 1.8Above world average — Beaver Orange badge draws attention

Suppressing low FWCI values avoids surfacing poor scores for new papers that haven't yet accumulated citations. A 2025 paper with FWCI 0.2 is completely normal.

All badge colors pass WCAG 2.2 AA (4.5:1 minimum for small text). Font sizes use rem throughout. Bronze OA badge uses black text on Solar Flare — white text on that color fails AA at 2.98:1. External link arrows (↗) omitted from markup — added automatically by the Drupal Link Purpose module.
